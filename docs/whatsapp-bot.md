# בוט תזכורות וואטסאפ

כשמגיע הזמן שנקבע לחזרה על ליד, **העובד המשויך מקבל וואטסאפ** עם
פרטי הליד — שם, טלפון, במה התעניין, ומה נאמר בשיחה הקודמת.

הבוט רץ על מחשב במשרד וממספר וואטסאפ ייעודי. אין תשלום ל-Meta.

---

## מה צריך לפני שמתחילים

1. **מחשב במשרד** שנשאר דלוק (Windows).
2. **Node.js גרסה 22 LTS** — <https://nodejs.org>. לא 26; הספרייה של
   וואטסאפ לא נבדקה מולה, וזה מחשב שאף אחד לא ידבג בו.
3. **כרטיס SIM ייעודי** עם וואטסאפ פעיל, בטלפון טעון שנשאר במשרד.
   ⚠️ **לא המספר העסקי הראשי.** אם וואטסאפ יחסמו את המספר, מחליפים
   סים וממשיכים; חסימת המספר הראשי היא אובדן כל היסטוריית השיחות
   עם הלקוחות, בלי דרך חזרה.

---

## התקנה — פעם אחת

### 1. הגדרת המפתח בשרת

ב-Vercel, במשתני הסביבה של הפרויקט, להוסיף:

```
WHATSAPP_API_KEYS=os_bot_בחר-מחרוזת-אקראית-ארוכה:בוט המשרד
APP_URL=https://onestop-crm-demo.vercel.app
```

ואז **Redeploy** — משתני סביבה נכנסים לתוקף רק בבנייה הבאה.

המפתח הזה נפרד ממפתחות הלידים בכוונה: הוא יושב על מחשב במשרד, ואין
סיבה שיוכל גם ליצור לידים.

### 2. הורדת הקוד למחשב במשרד

```
git clone https://github.com/zbyqy3753-beep/onestop-crm.git C:\onestop-bot
cd C:\onestop-bot\bot
npm install
```

### 3. הגדרות מקומיות

להעתיק את `.env.example` ל-`.env` ולמלא:

```
CRM_BASE_URL="https://onestop-crm-demo.vercel.app"
WA_API_KEY="os_bot_..."     ← החלק שלפני הנקודתיים מהשלב הראשון
```

### 4. חיבור הוואטסאפ

```
npm run pair
```

נפתח חלון עם קוד QR. בטלפון עם המספר הייעודי:

> וואטסאפ ← הגדרות ← מכשירים מקושרים ← **קישור מכשיר** ← לסרוק

כשמופיע `✓ מחובר בהצלחה` — סיימנו, אפשר לסגור.

### 5. הפעלה קבועה

לחיצה כפולה על **`install-task.cmd`** (יבקש הרשאות מנהל).

הוא רושם את הבוט כמשימה שמופעלת עם הדלקת המחשב, מפעילה את עצמה
מחדש אחרי כל נפילה, ומכבה את מצב השינה של המחשב.

### 6. בדיקה

לפתוח את **מסך ניהול המערכת** באתר. הרצועה למעלה אמורה להיות ירוקה
תוך דקה: `הבוט מחובר · נראה לפני כמה שניות`.

זו כל הבדיקה. אם היא ירוקה — הכול עובד.

## כשמשהו לא עובד

**הרצועה אדומה**
המחשב כבוי, אין אינטרנט, או שהתהליך נפל. לבדוק:
```
schtasks /query /tn OneStopWaBot /v /fo LIST
```
להפעלה ידנית: `schtasks /run /tn OneStopWaBot`

**הרצועה ענברית ואומרת "וואטסאפ מנותק"**
החיבור נשמט. בדרך כלל חוזר לבד. אם לא, מהתיקייה `bot`:
```
npm run pair
```

**בהודעות הלוג מופיע "הסשן נותק מהטלפון"**
מישהו הסיר את המכשיר המקושר, או שנלחץ "התנתק מכל המכשירים".
צריך לחבר מחדש:
```
rmdir /s /q auth
npm run pair
```
ואז `schtasks /run /tn OneStopWaBot`

**עובד לא מקבל תזכורות**
במסך ניהול המערכת, לבדוק אם יש לו תגית **"אין טלפון"**. עובד בלי
מספר טלפון תקין מדולג בשקט.

## דברים שכדאי לדעת

- **תזכורות יוצאות רק בין 08:00 ל-21:00.** חזרה שנקבעה לשעה אחרת
  נדחית לבוקר, לא נמחקת.
- **תזכורת שאיחרה ביותר מ-48 שעות מבוטלת.** אחרי סוף שבוע עם מחשב
  כבוי העובד לא יקבל ערימה של תזכורות ישנות.
- **שינוי תאריך החזרה מבטל את התזכורת הישנה** ויוצר חדשה.
- **ליד ללא שיוך לא מייצר תזכורת** — אין למי לשלוח.
- **סגירת הליד מבטלת תזכורת ממתינה.**
- הבוט לא שולח שום דבר ללקוחות. רק לעובדים.

## הגדרות חשמל

`install-task.cmd` כבר מטפל בזה, אבל אם המחשב עדיין נכנס לשינה:

```
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /hibernate off
```

כדאי גם להגדיר ב-Windows Update **שעות פעילות** כך שאתחולים
אוטומטיים יקרו בלילה.
