# dog (כלב) — דחוף ופרוס

הרץ את הרצף הזה מתוך `onestop-crm`, בסדר הזה, ועצור אם שלב נכשל.

1. **מצב העבודה** — `git status --short`. אם יש שינויים ב-`src/` שלא
   קומטו, זה חלק מהפריסה: הרץ `npx tsc --noEmit`, `npm run lint`
   ו-`npm run build`, ורק אם שלושתם נקיים צור קומיט בסגנון המאגר
   (כותרת בעברית כמשפט קובע, גוף שמסביר **למה**, ו-`Co-Authored-By`).
   אם אין שינויים לא-מקומטים — דלג ישר לשלב 3.

2. **בדיקה לפני דחיפה** — אם הקומיט כבר היה קיים ולא רצה עליו בנייה
   בסשן הזה, הרץ `npm run build` לפני הדחיפה. פריסה שנשברת בייצור
   יקרה יותר מ-30 שניות בנייה מקומית.

3. **דחיפה** — `git push demo master` ואחריו `git push origin master`.
   ⚠️ `demo` הוא הרימוט שמפעיל את הבנייה ב-Vercel; דחיפה ל-`origin`
   לבדה לא פורסת כלום.

4. **המתנה לפריסה** — פולינג ברקע על `npx vercel ls` עד שהשורה העליונה
   יוצאת מ-`Building`/`Queued`. אל תסיים את התור לפני שהסטטוס `Ready`.

5. **דיווח** — סטטוס הפריסה, משך הבנייה, וקוד תגובה מ-
   `https://onestop-crm-demo.vercel.app/login`. אם הפריסה נכשלה — הבא
   את הלוג עם `npx vercel logs` ואל תדווח על הצלחה.

**משתני סביבה:** אם השינוי תלוי במשתנה סביבה חדש, הגדר אותו ב-Vercel
**לפני** הדחיפה (`npx vercel env add <NAME> production`) — אחרת הקוד
עולה לייצור ונופל בשקט להתנהגות הישנה.
